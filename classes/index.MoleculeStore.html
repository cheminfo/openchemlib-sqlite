    Class MoleculeStore

    The write side and the identity of the library's tables (ocl_molecule, ocl_tile, ocl_bits, ocl_meta), in the application's own SQLite file. Everything it stores is computed by the library from the idCode alone: the canonical idCode, the atom count, the band, FragFp, the screen, both identity hashes, and how many molecules hold each FragFp, screen and function key. The application keys its own tables by the same id.

    Staticrebuild

    • rebuild(db: DatabaseSync, options?: RebuildOptions): Promise<RebuildResult>

      Brings a file to this build while the build that wrote it keeps serving it: the bits of the fingerprints whose keys changed are computed again from the idCodes and the bits counted again, beside those in use. Writes go on meanwhile and log what they change; the rebuild catches up on that log, and puts its tiles and counts in place in one short transaction. Resumable.
