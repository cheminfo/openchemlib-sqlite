    refoldAdvisable

    refoldAdvisable: boolean

    Whether calling foldPlanes() now would make searches faster: a fold is half done, a write below the watermark has left folded entries untrusted, or so many entries wait that the plane path is no longer taken. Always false for a database that never folded.
